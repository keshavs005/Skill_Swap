# SkillSwap reports

The three parameterized SQL datasets are ready for SQL Server and Microsoft Report Builder. Create three `.rdl` reports named SkillPopularity, SkillCreditEconomy, and SessionPerformance; add `@StartDate` and `@EndDate` DateTime parameters, paste the matching query into a dataset, then add grouped tables/charts using the selected columns. RDL layout cannot be executed or previewed in this workspace, so the manual Report Builder binding step is intentionally identified rather than claimed complete.
